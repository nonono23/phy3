==================================================
PhyGame（物理シミュレーションゲーム）仕様書
==================================================

1. 概要
本アプリケーションは、高校物理における「落体の運動（斜方投射、水平投射、鉛直投げ上げ）」を直感的に学習できるブラウザベースのシミュレーションゲームです。生徒は提示された問題に対して初速（v0）を計算・入力し、ターゲットに命中させることを目的とします。

2. システム構成
- フロントエンド: HTML5, CSS3, Vanilla JavaScript
- 描画: HTML5 Canvas API (2D)
- 音声: Web Audio API
- バックエンド/ログ収集: Google Apps Script (GAS) + Google Spreadsheet
- ホスティング: Netlify (想定)

3. ゲームモード（出題パターン）
出題は以下の3つのモードから各1問ずつ、ランダムな順番で合計3問出題されます。

3.1. 斜方投射 (Oblique)
- 概要: 地面から特定の仰角（30°, 45°, 60°）で撃ち出し、地上のターゲットに命中させる。
- 変数: xTarget (距離), thetaDeg (仰角), tHit (命中までの時間)

3.2. 水平投射 (Horizontal)
- 概要: 高さ H の崖から水平（仰角0°）に撃ち出し、地上のターゲットに命中させる。
- 変数: xTarget (水平距離), cannonY (崖の高さ), thetaDeg = 0

3.3. 鉛直投げ上げ (Vertical)
- 概要: 地面から真上（仰角90°）に撃ち上げ、上空の最高点にあるターゲットを通過させる。
- 変数: yTarget (ターゲットの高さ), thetaDeg = 90

4. 主要機能
4.1. 物理シミュレーション
- requestAnimationFrame を使用した描画ループ（animate関数）。
- 重力加速度 g = 9.8 m/s^2 とし、入力された初速（v0）と時間（t）からボールの現在座標 (x, y) を計算。

4.2. 計算スペース（Scratchpad）
- 生徒が公式を使って計算を行える電卓機能。
- 四則演算、括弧、平方根（sqrt()または√ボタンによる入力）、累乗（^記号）をサポート。
- safeEvaluate関数による安全な数式評価処理。
- 過去の計算履歴を保持し、計算結果をクリックすることで初速入力欄へ自動転記。

4.3. サウンド機能
- Web Audio APIを利用したオシレーターによる効果音生成（外部音声ファイル不要）。
- 発射音（ノイズ＋矩形波）、命中音（サイン波の和音）、ミス音（ノコギリ波の不協和音）。
- UI上のミュートボタンによる音声のON/OFF切り替え。

4.4. 学習サポート機能
- ヒント機能: 問題ごとに用意されたヒント（公式の提示や途中式の案内）を表示。
- 定数チップ: 計算に必要な数値（√2, √3, cosθ, gなど）をワンクリックで入力欄へコピー。
- 挑戦回数制限: 各問題につき最大3回までの入力制限。

5. ログ収集システム
生徒の学習プロセスを分析するため、アクションごとにローカルログを記録し、問題完了時にGASを経由してスプレッドシートへ送信します。

[送信される主要データ]
- ユーザーネーム, ユーザーID（ローカルストレージに保存）
- 問題番号, モード (oblique/horizontal/vertical)
- クリア可否
- かかった時間（秒）
- 挑戦回数, ヒント使用回数, 計算スペース利用回数
- 初速の入力履歴（配列）
- 計算式の入力履歴（配列）

6. UIレイアウト
- 左側パネル: 物理シミュレーションのCanvas描画領域（幅800px × 高さ360px）。
- 右側パネル: 問題文、定数チップ、初速入力フォーム、ヒント表示領域、結果バナー。
- 下部パネル: 計算スペース（入力欄、√ボタン、履歴表示領域）。
- オーバーレイ: 開始時のユーザーネーム入力画面、および全問終了時の結果発表画面。
